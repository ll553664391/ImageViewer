快看看图

打开一张图片，即可浏览它所在文件夹的所有图片

双击文件夹中的图片也可用本工具查看 · 方向键 / A D 翻页 · 滚轮缩放

总览
↑ ← A 上一张 · ↓ → D 下一张 · 滚轮缩放 · 拖动平移 · 0 适应 · S 设置 · F11 全屏 · Esc 退出

设置

主题

选择界面配色，默认暗色。

标题栏信息

勾选后在窗口标题栏显示图片的完整绝对地址，而非仅文件名。

默认看图程序

将本程序注册到系统“打开方式”中，随后在 Windows 设置里确认即可替换默认看图软件。
Windows 10/11 不允许程序静默修改默认关联，需要你在弹出的系统设置中点一下确认。

文件夹右键菜单

在文件夹上或文件夹空白处右键，增加“使用快看看图查看图片”。

程序位置

浏览历史

最近浏览的文件夹，每个文件夹只记录最近查看的一张图片（最多 20 个）
