# 快看看图（ImageViewer）

一个基于 **Tauri 2 + Vite** 的轻量级 Windows 看图工具。双击图片即可用本工具打开，并自动浏览该图片所在文件夹的全部图片；支持自然排序、键盘翻页、鼠标中心缩放、缩略图总览、明暗主题与 Windows 文件关联集成。

## 功能特性

- **单图 / 文件夹浏览**：传入任意图片路径，自动加载其所在文件夹的所有图片（不含子文件夹），按文件名自然排序（`img2` 排在 `img10` 之前）
- **位置计数**：窗口标题栏实时显示 `文件名 · 当前/总数 · 缩放%`；到首张或末张时提示，不循环
- **鼠标中心缩放**：滚轮以鼠标指针位置为锚点缩放；放大后可按住拖动平移，右下角显示缩略图总览与视口框
- **底部进度条**：淡绿色渐变进度条，与当前图片位置同步
- **显示绝对路径**：可选在标题栏显示图片完整绝对路径（设置中开启，持久保存）
- **明暗主题**：默认暗色，可在设置中切换白色主题，自动记忆；系统标题栏颜色随主题变化
- **Windows 集成**：
  - 注册为图片文件的“打开方式”（默认看图程序）
  - 文件夹 / 文件夹空白处右键菜单“使用快看看图查看图片”
  - 支持拖拽图片或文件夹到窗口打开
- **窗口默认最大化**启动
- **无菜单栏**：界面极简，操作全靠键盘、滚轮、右键菜单

## 快捷键

| 按键 | 功能 |
|------|------|
| `↑` / `←` / `A` | 上一张 |
| `↓` / `→` / `D` | 下一张 |
| 鼠标滚轮 | 以鼠标位置为中心缩放 |
| 按住拖动 | 放大后平移画面 |
| `+` / `-` | 放大 / 缩小 |
| `0` | 适应窗口 |
| `S` / `Ctrl+,` | 打开设置 |
| `Ctrl+O` | 打开图片 |
| `F11` | 全屏切换 |
| `Esc` | 退出全屏 / 关闭弹窗 |

## 安装

前往 [Releases](../../releases) 下载最新安装包：

- `快看看图_1.0.0_x64-setup.exe` — NSIS 安装包（推荐）
- `image-viewer.exe` — 免安装可执行文件，双击即用

安装后可在“设置”中注册为默认看图程序与添加文件夹右键菜单。

> Windows 10/11 不允许程序静默修改默认应用关联。点击“注册并打开系统设置”后，需在弹出的系统设置中手动确认一次。

## 从源码构建

环境要求：

- Node.js 18+
- Rust 1.77+（MSVC 工具链）
- Windows 10/11（含 WebView2 Runtime）

```bash
npm install
npm run tauri build
```

产物位置：

- 安装包：`src-tauri/target/release/bundle/nsis/快看看图_1.0.0_x64-setup.exe`
- 可执行文件：`src-tauri/target/release/image-viewer.exe`

开发模式：

```bash
npm run tauri dev
```

## 技术栈

- 前端：原生 HTML / CSS / JavaScript，Vite 7
- 后端：Rust，Tauri 2.12
- Windows 集成：`winreg`（注册表文件关联与右键菜单）
- 图标：Pillow 生成多尺寸 PNG / ICO
