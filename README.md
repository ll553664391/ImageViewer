# 快看看图（ImageViewer）

一个基于 **Tauri 2 + Vite** 的轻量级 Windows 看图工具。双击图片即可用本工具打开，并自动浏览该图片所在文件夹的全部图片；支持自然排序、键盘翻页、鼠标中心缩放、缩略图总览、右键菜单快捷操作、浏览历史、明暗主题与 Windows 文件关联集成。

## 功能特性

- **单图 / 文件夹浏览**：传入任意图片路径，自动加载其所在文件夹的所有图片（不含子文件夹），按文件名自然排序（`img2` 排在 `img10` 之前）
- **位置计数**：窗口标题栏实时显示 `文件名 · 当前/总数 · 缩放%`；到首张或末张时提示，不循环
- **鼠标中心缩放**：滚轮以鼠标指针位置为锚点缩放；放大后可按住拖动平移，右下角显示缩略图总览与视口框
- **底部进度条**：淡绿色渐变进度条，与当前图片位置同步
- **右键菜单**：看图时右键即可复制文件名 / 绝对地址、把当前图片复制到指定文件夹、打开浏览历史（详见下方「右键菜单」）
- **浏览历史**：按文件夹聚合记录最近 20 个浏览过的文件夹，每个文件夹只保留其最近查看的那张图片；点击记录即可跳回对应文件夹与图片。首页与右键菜单均可打开
- **复制目标记忆**：「复制到文件夹」默认打开上次成功复制到的目录；若该目录已失效，则回退到当前查看图片所在的文件夹
- **显示绝对路径**：可选在标题栏显示图片完整绝对路径（设置中开启，持久保存）
- **明暗主题**：默认暗色，可在设置中切换白色主题，自动记忆；系统标题栏颜色随主题变化
- **Windows 集成**：
  - 注册为图片文件的“打开方式”（默认看图程序）
  - 文件夹 / 文件夹空白处右键菜单“使用快看看图查看图片”
  - 支持拖拽图片或文件夹到窗口打开
- **窗口默认最大化**启动
- **秒开直达图片**：通过文件关联 / 右键菜单带图片启动时，窗口在图片解码完成后才显示，直接呈现图片，不再先闪过白屏和主页；只有单独打开程序时才显示主页
- **无菜单栏**：界面极简，操作全靠键盘、滚轮、右键菜单

## 右键菜单

在看图区域点击右键：

| 菜单项 | 功能 |
|--------|------|
| 设置 | 打开设置弹窗（主题、标题栏、默认程序、资源管理器右键菜单） |
| 打开图片 | 选择一张图片，并加载其所在文件夹 |
| 适应窗口 | 重置缩放为适应窗口 |
| 全屏 | 切换全屏 |
| **复制文件名** | 复制当前图片的文件名到剪贴板 |
| **复制绝对地址** | 复制当前图片的完整绝对路径到剪贴板 |
| **复制到文件夹…** | 选择目标文件夹，把当前图片复制过去；同名文件自动追加 ` (1)`、` (2)`，不会覆盖 |
| **历史记录** | 打开浏览历史面板，点击某条记录跳回对应文件夹与图片；可一键清空 |

无图片时，前三项文件相关操作会自动置灰。历史记录最多保存 20 个文件夹，仅保留每个文件夹最近查看的一张图片。

## 快捷键

| 按键 | 功能 |
|------|------|
| `↑` / `←` / `A` | 上一张 |
| `↓` / `→` / `D` | 下一张 |
| 鼠标滚轮 | 以鼠标位置为中心缩放 |
| 按住拖动 | 放大后平移画面 |
| `+` / `-` | 放大 / 缩小 |
| `0` | 适应窗口 |
| `S` / `Ctrl+,` | 打开设置 |
| `Ctrl+O` | 打开图片 |
| `Ctrl+F` | 打开文件夹 |
| `F11` | 全屏切换 |
| `Esc` | 退出全屏 / 关闭弹窗 |

## 安装

前往 [Releases](../../releases) 下载最新安装包：

- `快看看图_1.0.0_x64-setup.exe` — NSIS 安装包（推荐）
- `image-viewer.exe` — 免安装可执行文件，双击即用

安装后可在“设置”中注册为默认看图程序与添加文件夹右键菜单。

> Windows 10/11 不允许程序静默修改默认应用关联。点击“注册并打开系统设置”后，需在弹出的系统设置中手动确认一次。

## 从源码构建

环境要求：

- Node.js 18+
- Rust 1.77+（MSVC 工具链）
- Windows 10/11（含 WebView2 Runtime）

```bash
npm install
npm run tauri build
```

产物位置：

- 安装包：`src-tauri/target/release/bundle/nsis/快看看图_1.0.0_x64-setup.exe`
- 可执行文件：`src-tauri/target/release/image-viewer.exe`

开发模式：

```bash
npm run tauri dev
```

## 技术栈

- 前端：原生 HTML / CSS / JavaScript，Vite 7
- 后端：Rust，Tauri 2.12
- Windows 集成：`winreg`（注册表文件关联与右键菜单）、原生 Win32 剪贴板 API
- 图标：Pillow 生成多尺寸 PNG / ICO
